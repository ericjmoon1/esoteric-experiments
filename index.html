Esoteric programming languages

Programming, with unnecessary rules.

An esoteric programming language—usually shortened to esolang—is built to explore an unusual idea rather than to be practical. Some are jokes, some are puzzles, some deliberately make programming difficult, and some ask what code can look like in the first place.

That can mean programs made entirely from whitespace, colors, recipe instructions, Shakespearean dialogue, Scrabble scores, repeated words, or two-dimensional grids. The constraint is the point.

I made a small project for each language below. As you change the controls, the source view beside the project updates too, so you can see how the current choices change the strange-looking program. MOON, at the end, has a full editable in-browser interpreter.

01 / COW

COW

Cowculator

COW has twelve instructions, most written as capitalization variants of moo. The joke is that tiny changes in the same word become completely different operations.

SourceView full source code ↗

        
Try itarithmetic companion
42
17 + 25

      

      

        
About the language
COW is a 2003 Brainfuck variant by Sean Heber. It uses a tape-like memory model and twelve instructions; most commands are capitalization variants of moo, so changing a single letter can change the operation entirely.
Esolang Wiki ↗

        
What this project does
Cowculator lets you choose two numbers and one of four arithmetic operations. The browser computes the result while the source pane updates to show the current COW program snippet, making the language’s extremely small vocabulary visible.

      

    


    

      
02 / Whitespace
Whitespace
Invisible Day Finder
Whitespace ignores visible characters and treats only spaces, tabs, and line feeds as instructions. A valid program can therefore look completely blank.

      

        
SourceView full source code ↗

        
Try itcalendar companion
MONDAY
September 28, 2026

      

      

        
About the language
Whitespace is a 2003 imperative, stack-based language by Edwin Brady and Chris Morris. Only spaces, tabs, and line feeds are meaningful syntax; ordinary visible characters are ignored, which means a valid program can appear completely blank.
Esolang Wiki ↗

        
What this project does
Invisible Day Finder accepts a date and can return its weekday, day of year, or leap-year status. The source pane is intentionally blank until you reveal the same program using visible markers for spaces, tabs, and line feeds.

      

    


    

      
03 / Piet
Piet
Primary Color Mixer
Piet is a visual esolang inspired by Piet Mondrian. Instructions are encoded by transitions between colored regions rather than by words.

      

        
Source imageView source image ↗

About the language
Piet, created by David Morgan-Mar, is a stack-based visual language whose programs resemble abstract paintings. Operations are encoded by transitions between colored codels using cyclic hue and lightness changes rather than textual keywords.

INTERCAL was created by Donald R. Woods and James M. Lyon in 1972 with the explicit goal of resembling no existing programming language. It is famous for deliberately strange syntax, unusual operators such as Mingle and Select, and its famously unnecessary use of PLEASE.

My own
MOON
Machine-Oriented Orbital Notation
After exploring these languages, I made one of my own. MOON is a tape-based esoteric language whose source uses only celestial emoji and whitespace.

      
MOON is a small tape-based esoteric programming language I designed in 2026 around a celestial instruction alphabet. A program may contain only ten moon/space emoji commands and whitespace; memory cells are “planets,” the active pointer is the “astronaut,” and loops are “orbits.” The browser playground below interprets MOON source directly.

      

        
Language design
Execution starts on planet 0 with 8-bit cells initialized to zero. 🌒/🌘 change the current planet, 🚀/🛸 move the astronaut, 🌑 clears a planet, 🌕 outputs a character, ⭐ outputs a number, 📡 reads numeric input, and 🪐/☄️ form loops.

        
Related ideas
MOON belongs to the same broad tradition as tiny tape/cell languages such as Brainfuck, COW, and Ook!. Like Piet and Whitespace, its restricted visual alphabet is part of the language’s identity. MOON is not a one-for-one command substitution: it adds explicit zeroing, numeric I/O, and its own themed execution model.
